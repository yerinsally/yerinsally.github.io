📊
Data-Driven

행동 기반 인사이트

사용자의 행동과 비즈니스 맥락을 함께 읽어 인사이트를 도출하고, 결정에 쓰일 전략으로 제안합니다. 퍼널 · 세그먼트 · 리텐션 분석으로 「누가 왜 움직이는지」를 나눠 봅니다.

🧱
Data Governance

데이터 거버넌스

화면 속 행동이 분석할 수 있는 데이터로 남도록 설계합니다. 기획 단계의 로그 설계부터 배포 후 감시와 표준화까지 맡습니다.

SOFT SKILLS
🔍
Critical Thinking

비판적 사고

당연해 보이는 전제일수록, 반대편에서 데이터로 다시 묻습니다. 판정 기준은 결과를 보기 전에 정하고, 틀린 기준은 리뷰로 고칩니다.

⚡
Adaptability

빠르게 배우고 적용

새로운 도구와 분석 기법을 빠르게 익혀 실전에 바로 씁니다. SQL · Amplitude에서 Impala, Claude Code 스킬 제작까지 필요에 따라 역량을 넓혔습니다.

🤝
Co-Creation

구조화해 전달 · 협업

복잡한 데이터를 구조화해 명확하게 전달합니다. 개발 · 디자인 · 기획과 협업하고, 분석 결과를 실무가 바로 움직이는 형태로 제공합니다.
